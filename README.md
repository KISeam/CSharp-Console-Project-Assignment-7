# CSharp-Console-Project-Assignment-7

A simple C# console application developed using .NET 10.0.  
This project demonstrates the use of user-defined methods to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

---

## 📌 Project Overview

The application takes two numeric inputs from the user and performs arithmetic operations using separate methods:

- Addition
- Subtraction
- Multiplication
- Division

Each operation is implemented using a dedicated method to demonstrate modular programming and code reusability in C#.

- C#
- .NET 10.0 SDK
